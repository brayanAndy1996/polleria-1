# Frontend

Aplicación Next.js del sistema. Empieza por [la guía de frontend](../docs/FRONTEND.md).

- `src/app/`: rutas y pantallas.
- `src/components/`: componentes de interfaz.
- `src/app/globals.css`: estilos globales.
- `src/lib/api/`: cliente y funciones de acceso a la API.
- `src/config/`: configuración del entorno del frontend.

Desde la raíz: `pnpm dev:frontend`, `pnpm test:frontend`,
`pnpm typecheck:frontend` y `pnpm build:frontend`.
